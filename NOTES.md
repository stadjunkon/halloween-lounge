# Halloween Lounge — заметки по проекту

Концепт мобильного интерфейса для видео в соцсети (жанр «дизайн-инженерия»).
Это музыкальный плеер, где единственный источник света — вырезанная тыква со свечой.
Экран стартует в полной темноте. По тапу чиркает спичка, свеча разгорается, и свет тыквы проявляет интерфейс.
Музыка синтезируется прямо в браузере, а пламя мерцает и пульсирует в такт басу.

Состояние на 1 ноября 2026: готовая версия для записи видео. Опубликована как приватный артефакт claude.ai
(https://claude.ai/artifact/7rzdwetmWsTHLZTj58DzSc — ссылка привязана к старому аккаунту).

## Как запустить

- Открой `index.html` в Chrome (двойной клик или перетащи в окно браузера). Всё лежит в одном файле: картинки встроены, музыка синтезируется в коде.
- Нужен интернет только для шрифтов Google Fonts (Geist, Grenze Gotisch). Без интернета подставятся системные шрифты.
- Включи звук. Браузер не даёт звуку играть, пока на странице ничего не нажато, поэтому музыка начинается с первого нажатия.

### Клавиши (режим записи)

Клавиши ловятся по `e.code`, поэтому работают и на русской раскладке. Нажатия с Cmd, Ctrl или Alt игнорируются.

| Клавиша | Действие |
|---|---|
| F | Полный экран через Fullscreen API: чёрный фон, без интерфейса браузера |
| Space / Enter | Запуск анимации: спичка, вспышка, музыка. Если тыква уже горит — пауза и воспроизведение |
| R | Повтор: сброс в тёмное начальное состояние, через 0,9 с анимация запускается сама |
| − / + | Масштаб шагом 5% (40–160%), тост с процентом, значение сохраняется в localStorage (`hl-scale`) |
| 0 | Сброс масштаба на 100% |
| ← / → | Предыдущий и следующий трек |
| L | Зажечь или задуть свечу |
| H | Скрыть или показать подсказку с клавишами |

В полном экране подсказка с клавишами скрыта, а курсор исчезает через 1,5 с без движения мыши.
Мышью: тап по тыкве зажигает её или задувает, свечу-прогресс можно перетаскивать.

## Структура

```
index.html            готовая страница, собирается из src/ и render/final/ (коммитится как результат)
src/head.html         разметка и стили
src/scene.js          логика: смешивание кадров тыквы в WebGL, свет на интерфейсе, частицы, режим записи
src/sound.js          синтезатор и секвенсор на Web Audio (лаунж-бэнд: контрабас, Rhodes, щётки, терменвокс, винил)
src/tracks.js         три трека: гармония, бас, мелодия, темп
src/build.py          сборка index.html (картинки → WebP → data URI)
render/pumpkin.py     сцена Blender: тыква, резьба, свеча, дым, свет, камера (запускается без интерфейса)
render/render-all.sh  рендер пяти финальных кадров
render/final/         пять кадров, которые смешивает страница (900×900, AgX Punchy)
render/lookdev/       промежуточные тестовые рендеры (как шёл подбор света и дыма)
archive/              ранние версии страницы (см. «История»)
tools/check.js        headless-проверка в Playwright: свет, клавиши, мобильная ширина
```

## Как пересобрать

```bash
pip install pillow
python3 src/build.py              # → index.html
python3 src/build.py --artifact   # + dist/artifact.html (вариант без <html>/<head> для артефактов claude.ai)
```

Проверка (нужен Playwright с Chromium):

```bash
npm i -D playwright && npx playwright install chromium
node tools/check.js               # скриншоты в tools/out/
```

## Как перерендерить тыкву

1. Нужен Python с модулем `bpy`. Вариант: `pip install bpy` (bpy 5.x работает на Python 3.13). Или поставь Blender 5.x и запускай `blender -b -P render/pumpkin.py` с теми же переменными окружения.
2. Запусти `PY=python3 render/render-all.sh`.
3. На 4 ядрах CPU один кадр считается около 5 минут, все пять — около 25 минут.
4. Пересобери страницу: `python3 src/build.py`.

Параметры `pumpkin.py` задаются переменными окружения:

| Переменная | Что задаёт |
|---|---|
| `MODE` | `lit`, `unlit`, `candle` или `moon` |
| `RES`, `SAMPLES` | Разрешение и количество сэмплов рендера |
| `HAZE` | Плотность дыма |
| `HAZE_OFF` | Сдвиг рисунка дыма |
| `HAZE_SCALE`, `HAZE_DIST` | Масштаб и искажение шума дыма |
| `ANISO` | Анизотропия рассеяния в дыме |
| `CANDLE_W` | Мощность свечи |
| `CANDLE_DX` | Наклон пламени |
| `MOON` | Сила лунного света |
| `CAM_YAW` | Поворот камеры (0 — анфас) |
| `EXPO`, `LOOK` | Экспозиция и look AgX |
| `OUT` | Путь к файлу результата |

Лицо тыквы описано в функциях `eye()` и `grin()`: 9 клыков сверху, 8 снизу, неровные края «под нож».

## История и что сделано

1. **v1, `archive/v1-svg.html`.**
   - Плоская SVG-тыква по референсам из Pinterest (злая ухмылка, свечение в темноте, пугало в тумане).
   - Интерфейс проявляется светом тыквы, рот «поёт» под бас.
   - Свеча вместо полосы прогресса, процедурная музыка.
   - Пользователю понравилась композиция.
   - В архиве лежит промежуточная копия этой версии — до трёх последних исправлений (узкий рот, линии долек поверх лица, иконка паузы не переключалась).
2. **v2, `archive/v2-webgl-raymarch.html`.**
   - Интерфейс по референсу «тёмный UI с 3D-пилюлей в карусели».
   - 3D-тыква, которая считается в шейдере (raymarching), три тыквы в карусели.
   - Отвергнута: тыква выглядела «лоу-поли», а интерфейс местами слабый.
3. **v3, текущая `index.html`.**
   - Композиция из v1, стиль интерфейса по референсу Whop (онбординг: тёмные таблетки, белая кнопка, плитки кода, «Resend code», красное свечение снизу).
   - Тыква отрендерена в Blender Cycles.
   - Потом по просьбе пользователя: кнопки переделаны точно под язык Whop, убран мелкий текст внизу, добавлен режим записи (клавиши выше).

## Решения и почему

- **Тыква — офлайн-рендер, а не реальное время.**
  - Реализм референсов держится на подповерхностном рассеивании в мякоти, неровной резьбе и объёмных лучах сквозь дым.
  - В браузере на телефоне это не получить — v2 это показала.
  - Поэтому рендерю 5 кадров с одной камерой: потухшая тыква в лунном свете; горящая с пламенем по центру, влево и вправо; горящая с другим рисунком дыма.
  - Страница смешивает их в WebGL в линейном пространстве (sRGB → pow 2.2 → смесь → обратно). Отсюда вживую вспышка спички, мерцание, наклон пламени с движением лучей, медленный дрейф дыма и пульсация под бас — при фотографичной картинке.
- **Кадры сохранены уже с тонмаппингом AgX (8 бит), а не в HDR.**
  - Так проще и легче по весу.
  - Минус: свет нельзя «перекрутить» выше яркости кадра, вспышка выше 1 делается добавкой.
- **Внутренняя стенка тыквы — отдельная сглаженная оболочка, а не модификатор Solidify.** При толщине стенки больше радиуса ямки у стебля Solidify давал самопересечения, и точная булева операция с резьбой ломалась.
- **Дым не освещается лунным светом** (`visible_volume_scatter = False` у лунных ламп). Иначе фон становится серым, а интерфейсу нужен чёрный.
- **Музыка синтезируется Web Audio.**
  - Никаких внешних файлов и лицензий.
  - Секвенсор отдаёт события (бас, бочка, аккорды, мелодия), и они напрямую управляют пульсацией света. Это точнее, чем анализ спектра.
- **Масштаб артборда задаётся CSS `zoom`.**
  - Подгонка под высоту окна × пользовательский масштаб.
  - Холсты рендерятся с плотностью пикселей devicePixelRatio × масштаб (максимум 3).
  - Позиции элементов считаются через `offsetLeft`/`offsetTop`, а не `getBoundingClientRect`: браузеры по-разному пересчитывают прямоугольники при `zoom`.
- **Клики мышью снимают фокус с кнопок**, чтобы Space и Enter всегда работали как клавиши сцены.
- **Референсы в репозиторий не включены.** Это чужие картинки и видео (Pinterest, скриншоты Whop). Ниже они описаны словами.

### Референсы (описание)

- Злая светящаяся ухмылка в полной темноте.
- Пугало с головой-тыквой в сумеречном тумане (синий и сиреневый свет).
- Видео «Halloween Lounge»: мерцающая тыква, лучи из прорезей сквозь дым.
- Видео тыквы с длинными клыками и красной кромкой вокруг вырезов.
- Тёмный UI с 3D-пилюлей в карусели.
- Онбординг Whop: чёрный фон, оранжево-красное свечение, белая градиентная таблетка «Sign up», тёмная «I have an account», поле-таблетка email, плитки кода, «Resend code», пилюля «Back».

## Что не доделано и известные ограничения

- **Звук никто не слушал на слух.** Баланс громкостей инструментов может потребовать подстройки (`channel(...)` в `src/sound.js`).
- **Не проверено на реальном телефоне и в Safari.** Проверено только в headless Chromium с программным WebGL. Fullscreen API на iPhone для обычных страниц не работает.
- **Полный экран может блокироваться внутри артефакта claude.ai (iframe).** Для записи лучше открывать `index.html` напрямую.
- **Одна тыква на все три трека.** Идея: своя резьба на каждый трек. В `pumpkin.py` меняются `eye()` и `grin()`, рендер — плюс 25 минут на тыкву.
- **Дым в рендере статичный.** Движение получается из кроссфейда двух вариантов дыма и частиц на canvas. Идея: отрендерить короткий зацикленный ролик дыма.
- **Часть кнопок декоративная.** «Back» ничего не делает. «Like» и «Repeat» работают (Repeat зацикливает трек).
- **Подсказка «Tap it again to blow it out»** появляется после зажигания и попадёт в запись. Если мешает — убрать в `ignite()` в `src/scene.js`.
- **Возможные следующие шаги:**
  - тыква в стеклянной плитке, как иконка Whop на втором экране;
  - отдельный стартовый экран в стиле первого экрана Whop;
  - русская локализация текстов.
